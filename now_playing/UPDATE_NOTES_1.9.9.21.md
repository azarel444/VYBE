# VYBE v1.9.9.21 — Laser Tunnel + Drive quick flip

- Added a second, visually distinct club background: **Laser Tunnel**, featuring animated perspective polygon gates, radiating rails, crossing laser fans, atmospheric glow, and streaming particles. No disco ball, stage fixtures, or LED grid.
- Added **Album Art + Laser Tunnel** as a separate source. Both new backgrounds respect existing club blend modes and animation speed and use the album-derived palette in Auto.
- Fixed Orbit's conditional ghost-art overlay for the new album + tunnel source.
- Added a landscape **swap sides** button to Drive's on-screen playback controls. It updates the existing persisted `driveSwap` setting; the map hole and information panel change together.
- Existing Club Light Show and existing saved background source values are preserved.
