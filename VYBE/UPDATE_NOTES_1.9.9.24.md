# VYBE 1.9.9.24 — Focused bars and layout swap

- Removed artwork-refresh shortcut from the floating controls. Automatic artwork lookup remains available.
- Added persistent horizontal layout swap in floating controls for landscape Side by Side and Edge to Edge; retained Drive's independent swap.
- Focused theme Bars mode now uses visualizer bars on both screen edges (as in Typo), instead of underneath the artwork.
- Increased Focused Bars artwork size to fill space freed by removing the visualizer ring and bottom bars.

Known limitation: layout swaps for Fan, Diagonal, Record Cut, Typo and Orbit are not implemented in this update. Flutter/Android build testing is required.
